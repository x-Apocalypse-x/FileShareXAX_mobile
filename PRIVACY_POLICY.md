# Политика конфиденциальности
## FileShare XAX mobile

Последнее обновление: 17.05.2026

### 1. Общие положения

Приложение FileShare XAX mobile ("Приложение") разработано для обмена файлами в локальной сети между устройствами пользователя.

### 2. Какие данные мы собираем

Приложение НЕ собирает, НЕ хранит и НЕ передает:
- Персональные данные пользователей
- Данные о местоположении (за исключением сканирования Wi-Fi сети для поиска серверов)
- Контактную информацию
- Идентификаторы устройства

Приложение получает доступ к:
- Файлам на устройстве (только для загрузки на сервер пользователя)
- Хранилищу устройства (для сохранения скачанных файлов)
- Wi-Fi сети (для обнаружения серверов в локальной сети через mDNS)

### 3. Как используются данные

Все данные обрабатываются **локально** на устройстве пользователя:
- Файлы передаются только между устройством пользователя и его личным сервером FileShare XAX
- Данные не передаются через интернет
- Данные не отправляются на сторонние серверы
- Данные не используются для аналитики или рекламы

### 4. Разрешения приложения

Приложение запрашивает следующие разрешения Android:
- **READ/WRITE_EXTERNAL_STORAGE** — для чтения и сохранения файлов
- **ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION** — для сканирования Wi-Fi сети и обнаружения серверов в локальной сети (требуется Android)
- **REQUEST_INSTALL_PACKAGES** — для установки APK-файлов, скачанных с сервера
- **INTERNET** — только для проверки обновлений приложения

### 5. Безопасность

- Все данные передаются в зашифрованном виде (HTTPS)
- Приложение не хранит файлы на своих серверах (серверы принадлежат пользователю)
- Пользователь контролирует все передаваемые файлы
